# 07 开发计划与验收

## 1. 阶段划分

全部阶段属于第一版范围，按依赖顺序推进；每阶段结束时可运行、可演示。时间安排由用户决定，本文不做估算。

```mermaid
flowchart LR
  M0["M0 脚手架与技术验证"] --> M1["M1 文档库与阅读"]
  M1 --> M2["M2 命令面板与搜索"]
  M1 --> M3["M3 导入与校验"]
  M2 --> M4["M4 AI 检索与 RAG"]
  M3 --> M4
  M4 --> M5["M5 增强渲染与分发"]
```

M2 与 M3 文件边界不重叠（palette/search 与 importer/library 校验），可并行。

## 3. 验收标准

### 功能验收（逐条对照 01-需求规格.md）

1. 用 04 中的提示词让 agent 抓取一个英文站点（如 Riverpod），生成的库在 flDoc 中自动出现，「校验文档库」无 E 级错误。
2. 阅读：代码高亮与复制、提示块、表格、任务列表、Mermaid、公式、图片正确显示；中/英切换后锚点位置保持。
3. 侧边栏：Ctrl+B 切换；两种收起形态都可用；版本下拉切换后打开同路径页面。
4. Ctrl+F：高亮、计数、上下跳转、Esc 清除。
5. 全局搜索：当前库/全部库切换；结果回车跳转并高亮命中；无结果出现 AI 智能搜索入口。
6. 符号搜索：symbols 命中跳转到锚点；无 symbols 的纯 Markdown 库走代码块兜底。
7. 所有设置项都能通过命令面板修改，与设置页即时一致。
8. AI：未配置时引导；配置后 AI 智能搜索返回混合结果；RAG 流式回答带可点击引用；会话历史重启后可继续。
9. 窗口：置顶、透明度、位置记忆、关闭到托盘、托盘退出、开机自启。
10. 外链：指向已抓取页面的绝对 URL 在本地打开，其余用系统浏览器。
11. 安装包在干净的 Windows 11 上安装后可运行，卸载不删除文档库。

### 质量验收

- `flutter analyze` 无错误。
- 单元、widget、集成测试全部通过。
- 达到 NFR-01 至 NFR-06。

## 4. 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| Mermaid 离屏 WebView2 渲染不可行或慢 | Mermaid 显示 | M0 验证；备选内嵌 WebView2 控件或显示源码 |
| 自研块级渲染器工作量大 | M1 进度 | 解析用成熟 `markdown` 包，只自研渲染；先覆盖契约要求的元素 |
| 长页面 Ctrl+F 与懒加载冲突（未构建的块无法高亮） | 查找体验 | 查找基于解析后的块文本，不依赖已构建 Widget；跳转时先滚动到块再高亮 |
| agent 产出质量不稳定（漏翻译、锚点不一致） | 阅读与引用 | 提示词自检 + 阅读器校验 V09/V10/V17；增量更新可局部修复 |
| JS 渲染站点 agent 抓不到正文 | 导入失败 | 提示词要求改用浏览器渲染抓取，失败页列入报告 |
| 嵌入接口限流或计费策略变化 | 索引构建 | 退避重试、可关闭自动索引、可换 base_url/模型 |
| 向量数据规模增长（多库） | 内存与查询 | 按查询范围加载；超过阈值时提示仅索引常用库 |
| fluent_ui 与新 Flutter 版本兼容性 | 构建 | M0 锁定可用版本组合 |
| WebView2 Runtime 缺失（少数 Win10） | Mermaid | 降级显示源码；安装包可选附带 Evergreen Bootstrapper |

## 5. 回滚

- 每个阶段在独立分支开发，合并前测试通过；问题可按阶段回退。
- 文档库对 flDoc 只读，应用故障不会损坏库数据；应用数据（设置、索引、历史）可删除重建，向量索引可通过「重建向量索引」恢复。
