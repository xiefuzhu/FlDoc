# flDoc 设计文档

flDoc 是一个 Windows 桌面悬浮文档阅读器：由 AI agent 预先把教程站点爬取为本地 Markdown 文档库，写代码时把 flDoc 置顶在屏幕一角阅读、搜索、向 AI 提问，不需要打开浏览器。

## 需求确认记录

以下决策来自 4 轮需求确认，是后续实现的依据。

| 主题 | 决策 |
|------|------|
| 名称 | flDoc |
| 视觉风格 | Fluent（Win11 风格，Mica 背景），参考 WPF UI Gallery 的侧边导航 |
| 侧边栏 | 可收起；收起形态支持「完全隐藏」与「图标栏」两种，设置中切换 |
| 侧边栏层级 | 文档库 → 章节 → 页面；库名旁有版本下拉框；不设侧栏搜索框 |
| 页内大纲 | 不常驻，通过命令面板「跳转到标题」 |
| 启动页 | 文档库卡片总览（Home） |
| 窗口 | 自带置顶开关、透明度、无边框极简标题栏、记住位置大小、托盘；不要全局显隐热键；不要贴边/紧凑模式 |
| 关闭行为 | 关闭 → 最小化到托盘，托盘菜单退出 |
| 开机自启 | 支持，默认关闭 |
| 阅读 | 代码高亮 + 一键复制、后退/前进、记住阅读位置、字号缩放 |
| 渲染扩展 | 表格、提示块、任务列表、Mermaid、LaTeX |
| 外链 | 优先跳到本地库内已爬取页面，找不到再用系统浏览器 |
| 翻译 | 爬取时由 agent 翻译为中文，保留英文原文；阅读器全局中/英切换并记忆 |
| 本页搜索 | Ctrl+F |
| 全局搜索 | 命令面板（Ctrl+Shift+P，无前缀，菜单选择）→ 全局搜索；ripgrep 打包进软件；默认当前库，可切全部库；结果在面板内带上下文预览，回车跳转并高亮 |
| 函数搜索 | symbols.json 符号索引 + rg 正则兜底 |
| AI 搜索 | rg 无结果时提示，也可随时手动；rg 关键词 + 向量语义混合召回，合并重排 |
| AI 回答 | RAG；右侧可收起 AI 面板，流式输出，引用可点击跳转；多轮追问，会话历史本地保存 |
| AI 配置 | 两个独立配置：对话模型（OpenAI 兼容，任意服务商）+ 嵌入模型（默认硅基流动 BAAI/bge-m3）；未配置时弹窗引导；OOBE 可配置 |
| 快捷键 | 不配功能直达键，全部走命令面板；保留基础键 Ctrl+Shift+P / Ctrl+F / Ctrl+B / Alt+←→ / Ctrl+=- / Esc |
| 设置 | 侧栏底部设置页 + 命令面板可修改全部设置项；settings.json 存普通设置，API Key 存 Windows 凭据管理器 |
| 主题 | 亮/暗/跟随系统、强调色、正文/代码字体、行宽 |
| 文档库位置 | 支持多个库根目录，默认 `%USERPROFILE%\flDocLibrary` |
| 库格式 | 契约格式（manifest.json + front matter + symbols.json）与纯 Markdown 文件夹都支持；提供「为此文件夹生成 manifest」命令 |
| 多版本 | 同库内版本切换器 |
| 图片 | 下载到库内 assets/，相对路径引用 |
| 增量更新 | 按 URL 去重，只更新有变化的页面 |
| 刷新 | 监听库目录，自动刷新 |
| 校验 | 阅读器内「校验文档库」命令 + 提示词要求 agent 自检 |
| 导入 | 命令面板「导入文档库」填参数，生成提示词并复制到剪贴板 |
| 界面语言 | 中文 |
| 首版范围 | 第一版即包含 AI 搜索与 RAG |
| 分发 | Inno Setup 安装包 |

## 环境基线

- Flutter 3.47.7 stable / Dart 3.13.5（2026-11-22 在本机检测）
- 目标平台：Windows 10 1809+ / Windows 11（Mica 仅 Win11 生效，Win10 退化为纯色背景）
