# 01 需求规格

编号规则：`FR-模块-序号`。优先级：P0 首版必须，P1 首版应有。本软件首版范围包含全部 P0 与 P1。

## 1. 整体布局

```
+--------------------------------------------------------------+
| [置顶] 页面标题 / 库名                       [-] [x]   标题栏 |
+------------------+------------------------------+------------+
| [=] 库名 [版本v] |                              |            |
| Home             |          正文区              |  AI 面板   |
| -----------      |   (Markdown 渲染，限宽居中)   | (可收起)   |
| > 章节           |                              |            |
|    页面          |          [Ctrl+F 查找条]     |            |
|    页面          |                              |            |
| > 章节           |                              |            |
|                  |                              |            |
| 设置             |                              |            |
+------------------+------------------------------+------------+
```

- 三栏：侧边栏（可收起）、正文区、AI 面板（默认收起）。
- 命令面板为浮层，出现在窗口顶部居中。

## 12. 文档库管理与导入

详见 [03-文档库契约.md](03-文档库契约.md)、[04-导入提示词.md](04-导入提示词.md)。

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-LIB-01 | 扫描所有库根目录下的一级子目录：有 manifest.json 按契约读取；没有但含 .md 文件按纯 Markdown 库读取 | P0 |
| FR-LIB-02 | 监听库根目录，变化防抖后增量重载；manifest 解析失败时保留上一次成功状态并提示 | P0 |
| FR-LIB-03 | 同库多版本：版本下拉框切换，切换后尽量打开同路径页面，不存在则打开版本首页 | P0 |
| FR-LIB-04 | 命令「文档库: 导入文档库」：表单填写来源 URL、库 ID、库名、版本、目标根目录、抓取范围、最大页数、是否翻译；生成提示词并复制到剪贴板，同时显示预览 | P0 |
| FR-LIB-05 | 命令「文档库: 校验文档库」：输出错误/警告列表，条目可点击定位到文件或页面 | P0 |
| FR-LIB-06 | 命令「文档库: 为此文件夹生成 manifest」：为纯 Markdown 库生成契约 manifest.json（不改动 .md 文件，已存在时需确认覆盖） | P1 |
| FR-LIB-07 | 库 ID 跨根目录冲突时两者都显示，后者标注所在根目录，并在校验中报错 | P1 |

## 13. 非功能需求

| 编号 | 需求 |
|------|------|
| NFR-01 | 冷启动到 Home 可交互：库总页数 5000 以内时目标小于 2 秒（不含向量索引） |
| NFR-02 | 全局搜索：5000 页库首批结果目标小于 300 毫秒 |
| NFR-03 | 打开 1 万行级长页面不卡顿（按块懒加载渲染） |
| NFR-04 | 离线可用：除 AI 功能外不依赖网络 |
| NFR-05 | 安全：调用 rg 只用参数数组不经过 shell；Markdown 不执行脚本；密钥不落明文 |
| NFR-06 | 文档库对 flDoc 只读：除「生成 manifest」命令外不修改库内文件；索引、状态均写入应用数据目录 |
