# 05 命令面板与快捷键

## 1. 命令面板交互

- `Ctrl+Shift+P` 打开，浮层位于窗口顶部居中，宽度为窗口宽度的 60%（最小 420、最大 720 逻辑像素）。
- 无前缀：输入框直接对命令标题、分类、关键词做模糊匹配（支持拼音首字母，如 `qjss` 匹配「全局搜索」）。
- 列表每项显示：分类前缀（如「搜索:」）、标题、当前值（设置类命令，如「主题: 跟随系统」）、说明。
- 空输入时先显示「最近使用」（最多 5 条），再按分类显示全部命令。
- 子模式：选择带后续输入的命令后，面板进入子模式，顶部显示面包屑（如「全局搜索 >」），输入框占位符变为该模式提示。输入框为空时按 Backspace 返回上一级；Esc 直接关闭面板。
- 键盘：`↑` `↓` 移动，`PageUp` `PageDown` 翻页，`Enter` 执行，`Tab` 在子模式的开关芯片间切换焦点，`Esc` 关闭。
- 不可用命令（如无当前页时的「跳转到标题」）不显示。

### 子模式类型

| 类型 | 说明 | 用于 |
|------|------|------|
| 选项列表 | 从固定枚举中选，当前值带勾 | 主题、侧边栏收起形态、语言等 |
| 文本/数值输入 | 输入后 Enter 确认，带校验提示 | 字号、透明度、行宽、base_url |
| 动态结果 | 输入即查询，结果流式追加 | 全局搜索、符号搜索、打开页面、跳转到标题 |
| 表单 | 多字段表单在面板内展开 | 导入文档库、AI 模型配置 |
| 确认 | 危险操作二次确认 | 删除会话、覆盖 manifest、重建索引 |

### 全局搜索子模式

```
+-----------------------------------------------------------+
| 全局搜索 >  [ provider override                        ]  |
| [当前库: Riverpod v] [Aa 大小写] [ab 全词] [.* 正则]       |
+-----------------------------------------------------------+
| 符号                                                       |
|   ProviderScope.overrides   property   核心概念/测试        |
| 快速开始 · Riverpod 3.x                           3 处命中  |
|   L42  使用 ProviderScope 的 overrides 参数...              |
| 测试 · Riverpod 3.x                               5 处命中  |
|   L18  ...                                                  |
+-----------------------------------------------------------+
| 共 8 处 / 2 个页面    Enter 打开   无结果时可用 AI 智能搜索 |
+-----------------------------------------------------------+
```

- 范围芯片：当前库（默认，取设置 `search.defaultScope`）/ 全部库，Tab 聚焦后 Space 切换。
- 结果为空时列表只有一项：「用 AI 智能搜索 "<输入>"」，Enter 进入 AI 智能搜索子模式（设置 `ai.suggestOnNoResult` 控制）。

## 3. 快捷键

按需求不为功能配置直达键，只保留以下基础键，固定不可改。

| 快捷键 | 作用 | 作用域 |
|--------|------|--------|
| `Ctrl+Shift+P` | 打开命令面板 | 全局（窗口内） |
| `Ctrl+F` | 本页查找 | 正文区有页面时 |
| `Enter` / `Shift+Enter` | 下一个 / 上一个匹配 | 查找条 |
| `Ctrl+B` | 切换侧边栏 | 全局 |
| `Alt+←` / `Alt+→` | 后退 / 前进 | 全局 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大 / 缩小 / 重置字号 | 全局 |
| `Esc` | 关闭命令面板 / 查找条 / 对话框 | 当前浮层 |
| `Enter` / `Shift+Enter` | 发送 / 换行 | AI 面板输入框 |

不注册任何系统级全局热键。焦点在文本输入框时，`Ctrl+B`、`Alt+←→` 等不拦截输入框自身的行为（输入框内的编辑快捷键优先）。
